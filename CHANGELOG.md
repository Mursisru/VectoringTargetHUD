# Changelog

All notable changes to this project are documented in this file.

## v1.0.0

Initial public release.

- Added Flight HUD direction marker plugin for selected air targets.
- Implemented prism wireframe marker rendering with configurable visuals.
- Added long-range readability behavior up to 80 km marker range.
- Added delayed marker reveal with damped blink appearance effect.
- Added anti-cheat tracking behavior (frozen hold state, no live hidden tracking).
- Added runtime HUD-theme live color sampling and hold-state color behavior.
- Added configuration entries for marker behavior and visuals via BepInEx config.
